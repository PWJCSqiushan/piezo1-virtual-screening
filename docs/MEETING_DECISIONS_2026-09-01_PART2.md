# 2026-09-01 组会后半段：正式决策、纠错与执行清单

## 一句话结论

`生科方案2.0.docx`继续作为主流程，但以本文件记录的会议修订为准：四个结构独立完成三工具口袋预测，DrugCLIP/GNINA输出候选药物分子，Step 8对口服倾向与吸入复核分流，后续只对极少量候选开展MD与MM-GBSA。

## 已确认并进入实施的决定

1. 正式结构为8YEZ、8ZU3、8YFC、9VMX；8ZU8只作参考。每个结构独立运行DoGSite3、fpocket、P2Rank，不跨构象寻找共同口袋。
2. 三工具完成后，先保存客观字段`support_count=2`或`support_count=3`，再显示Tier名称。fpocket未完成时，双工具匹配只是预检查。
3. 最终交付必须向后推进到“候选药物分子 + 证据链 + 可复现程序”，不能只停留在口袋或结合位点。
4. 代码必须支持分步运行。每一步保存输入、原始输出、标准化结果、日志、版本、参数和可用于PPT的图/表。
5. Step 8不再把SwissADME的口服相关规则当作一票否决。符合项和不符合项都要保留完整输出；不符合口服导向规则的分子进入“吸入/专家复核分支”，交药学指导老师判断。
6. ADMETlab 3.0负责广谱ADME、理化、药化友好性和不确定性；ProTox 3.0作为团队首选的计算毒性筛查。ADMETlab毒性字段仍保留作审计，但不作为团队主要毒性结论。
7. MD和MM-GBSA不提前启动。只有口袋、候选分子、对接姿势和参数全部就绪后，才对最终1–3个候选在膜环境中评估。

## 必须纠正的表述

| 会议口头表述 | 可用于报告的准确表述 |
|---|---|
| Drug-likeness Yes就是可口服 | 通过某个口服导向的经验规则，只能用于早期优先排序，不证明真实口服吸收、有效性或安全性 |
| Drug-likeness No就不是药 | 未通过某个经验规则；COPD吸入方向不得因此自动删除，应转专家复核 |
| 三工具共同口袋结合力更强 | 三工具共同支持只提高“该区域像口袋”的计算置信度，结合强弱要由后续对接、MD/MM-GBSA和实验评估 |
| ProTox开源 | 当前可确认的是面向学术/非商业用户的免费Web服务和限流API；不能在未见源码许可证前写成“整套开源” |
| SwissADME/ProTox证明肝肾安全 | 都是早期计算预测，只能做风险提示和优先级，不能替代实验与临床安全评价 |

## Step 8的可执行数据流

```text
DrugCLIP/GNINA候选（compound_id + canonical SMILES）
→ SwissADME：理化、GI吸收估计、Drug-likeness、PAINS等
→ ADMETlab 3.0：广谱ADME/药化指标及不确定性
→ ProTox 3.0：团队主要计算毒性筛查
→ 不删除原始数据
→ 分为 oral_priority / inhalation_expert_review / general_expert_review
→ 导出一张全量专家审核表
```

具体机器可读策略见`config/compound_assessment.json`。

## PPT必须保留的逐步证据

1. Step 1：四个PDB的结构清单、变体/MDFIC状态和处理范围。
2. Step 2：每个结构的三工具原始口袋数量和代表性可视化。
3. Step 3–5：同结构内匹配示意、支持数、共同残基和标准化口袋PDB；不要贴满所有原始口袋。
4. Step 6–7：DrugCLIP输入格式、候选分子排名和失败记录。
5. Step 8：SwissADME、ADMETlab、ProTox的全量汇总表与分支理由。
6. Step 9：GNINA docking box、代表性姿势和多种评分。
7. Step 10–11：若真正完成，再展示体系、平衡检查、轨迹指标和MM-GBSA；未完成则明确列为扩展验证，不伪造截图。

## 仍未解决，禁止程序擅自拍板

1. **Tier编号冲突**：原方案2.0和本次会议前文写“三工具=Tier 1、双工具=Tier 2”，但计算组后续收到的直接要求是“双工具=T1、三工具=T2”。当前配置暂时保留后一规则；底层数据一律以`support_count`为权威，待团队书面确认后再统一标签。
2. **ADMETlab是否完全删除**：转写中出现“直接删了”的口头句子，但前后更完整的共识是“保留ADMETlab综合指标，用ProTox替代主要毒性结论”。本实现采用后者，同时保留所有原始列，等待手工纪要确认。
3. **吸入候选的具体阈值**：需药学指导老师给出评审字段和淘汰规则，程序目前只分流、不自动淘汰。
4. **研究药理方向**：仍需明确要找PIEZO1激动剂、抑制剂还是一般调节剂；DrugCLIP/docking分数本身不能判断功能方向。
5. **MD环境**：脂质组成、质子化、离子浓度、力场、配体参数、模拟时长和硬件必须由有经验的成员审核。

## 计算组当前最直接的工作

1. 先完成8YFC、9VMX的DoGSite3结果回收和双工具预检查。
2. 找到Linux/WSL/HPC补跑fpocket，才能生成真正的三工具`support_count`。

4. 在候选分子出现前先准备Step 8的统一表头和批处理接口，不虚构分子结果。
5. 将队长/老师对Tier命名、ADMETlab保留范围和吸入筛选条件的书面确认更新进配置。
